Voice chat: a first example theme for GalleonCore.

Pictures: drawn for this theme by Paul Woisard, from plain shapes (see PROVENANCE.md in the source folder). CC-BY-SA-4.0.

Before the keys do anything, give your voice chat application these keyboard shortcuts. The keys send F13 to F17, which no application uses by default; in the application's shortcut settings, press the matching key on the module when it asks you to record the shortcut:
  Mute microphone      F13
  Deafen               F14
  Push to talk         F15 (held while the key is pressed)
  Turn camera on/off   F16
  Share screen         F17

On some Linux desktops (Wayland) an application only sees such a shortcut while its window has the focus.

The "Discord" key starts the application if it is installed (deb, Flatpak or Snap). No logo of any application is included.
