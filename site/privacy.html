What this site does

This is a static website hosted by Cloudflare Pages. It has no account, payment form or advertising. Visitor statistics are optional and require your consent. Cloudflare receives the technical requests needed to serve its pages and files, such as your IP address and browser information; Cloudflare determines its own handling and retention of those server logs. See the Cloudflare privacy policy. GitHub hosts the source code and downloadable releases; it receives your request data when you follow those links.

Distribution figures are generated from public GitHub, Launchpad, COPR and AUR package data in GitHub Actions. Direct-package baselines are refreshed daily; repository counts are checked daily. These are aggregate package statistics, not a record of visits to this website or a way to identify its visitors.

Storage on your device

The site stores galleoncore-lang to remember your language and galleoncore-external-v1 to remember whether you allowed optional external content. These values stay in your browser's local storage until you change the choice or clear site data. Matomo tracking cookies are disabled.

Optional external content

By default, status badges, web fonts and live download counts are not loaded from other sites. If you choose “Allow optional content”, your browser requests fonts from Google Fonts, badges from GitHub and Shields.io, and current release counts from the public GitHub API and AUR votes from the AUR RPC API when you open the page. Those providers then receive ordinary request data such as your IP address and browser details, and apply their own policies. Refusing leaves local text labels, system fonts and the last daily direct-package snapshot; the site remains usable. Change your choice using “Privacy choices” below at any time. The demo video contacts YouTube only when you click to play it; YouTube may then process your request under its own privacy policy. Links to external download or documentation sites are contacted only when you follow them.

Optional analytics (Matomo)

Choosing “Allow optional content” loads the self-hosted Matomo JavaScript tracker from stats.social-hub.fr (site ID 5). It measures page views, referring sites and link clicks to understand the project's audience. Tracking cookies are disabled. The Matomo server receives technical request data, potentially including your IP address and browser information; it is not used for advertising. No request is made to Matomo before you consent. Refusing or withdrawing your consent stops tracking. Use “Privacy choices” below to change your decision; this choice also controls the other optional content.

Your rights

For a question about data this project controls, or to exercise applicable access, correction, deletion or objection rights, write to the contact above. You may also complain to the French data-protection authority, the CNIL. For data handled by Cloudflare, GitHub or another external provider, consult that provider's policy and contact channels.

Qué hace este sitio

Es un sitio web estático alojado en Cloudflare Pages. No tiene cuentas, formularios de pago ni publicidad. Las estadísticas de visitas son opcionales y requieren tu consentimiento. Cloudflare recibe las solicitudes técnicas necesarias para servir sus páginas y archivos, como tu dirección IP y la información del navegador; Cloudflare decide cómo trata y durante cuánto tiempo conserva esos registros del servidor. Consulta la política de privacidad de Cloudflare. GitHub aloja el código fuente y las versiones descargables; recibe los datos de tu solicitud cuando sigues esos enlaces.

Las cifras de distribución se generan en GitHub Actions a partir de datos públicos de paquetes de GitHub, Launchpad, COPR y AUR. Las cifras base de los paquetes directos se actualizan a diario; los contadores de los repositorios se comprueban a diario. Son estadísticas agregadas de paquetes, no un registro de las visitas a este sitio ni un medio para identificar a sus visitantes.

Almacenamiento en tu dispositivo

El sitio guarda galleoncore-lang para recordar tu idioma y galleoncore-external-v1 para recordar si permitiste el contenido externo opcional. Contenido externo opcional

De forma predeterminada, las insignias de estado, las fuentes web y los contadores de descargas en directo no se cargan desde otros sitios. Si eliges «Permitir el contenido opcional», tu navegador solicita al abrir la página las fuentes a Google Fonts, las insignias a GitHub y Shields.io, las cifras actuales de las versiones a la API pública de GitHub y los votos del AUR a la API RPC del AUR. Esos proveedores reciben entonces los datos habituales de la solicitud, como tu dirección IP y detalles del navegador, y aplican sus propias políticas. Si lo rechazas, se mantienen las etiquetas de texto locales, las fuentes del sistema y la última instantánea diaria de los paquetes directos; el sitio sigue siendo utilizable. Los sitios externos de descarga o documentación solo se contactan cuando sigues sus enlaces.

Analítica opcional (Matomo)

Elegir «Permitir el contenido opcional» carga el rastreador JavaScript de Matomo, alojado por nosotros, desde stats.social-hub.fr (sitio n.º 5). El servidor de Matomo recibe datos técnicos de la solicitud, que pueden incluir tu dirección IP y datos del navegador; no se usan con fines publicitarios.
