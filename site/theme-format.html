Theme file format (version 1)

A theme is a page of keys for the Stream Deck module of the Corsair Galleon 100 SD, with a colour, optional dial settings and the pictures it needs. A .gctheme file carries it from one computer to another. Status: Bosun installs and exports this format; it has not been confirmed on the module yet. The same text is kept in the repository as docs/THEME_FORMAT.md.

The file

A .gctheme file is a zip archive whose entries are stored, not compressed (for example zip -0 -X my.gctheme theme.json icons/*). Pictures are already compressed, and refusing compression removes any risk of a decompression bomb. To look inside, rename it to .zip.

EntryRequiredContent and limits
theme.jsonyesThe manifest, up to 128 KiB.
credits.txtnoPlain UTF-8 text, up to 16 KiB.
icons/<name>.pngif usedA PNG key picture, up to 256 KiB and 512 × 512 pixels; at most 24. Every picture must be used by a key.
wallpapers/<name>.jpgnoA JPEG screen picture, up to 2 MiB and 4096 × 4096 pixels; at most 4.

Nothing else is accepted. File names use letters, digits, ., _ and - only. The archive is at most 24 MiB with at most 64 entries. Pictures are checked by their content, not their extension.

The manifest

{
  "formatVersion": 1,
  "id": "discord",
  "name": "Discord",
  "author": "A. Person",
  "license": "CC-BY-SA-4.0",
  "description": "Voice and chat keys for Discord",
  "color": "#5865F2",
  "keys": [
    { "key": 0, "label": "Mute", "icon": "mute.png",
      "action": { "type": "key", "key": "kp1" } },
    { "key": 1, "label": "Discord", "icon": "discord",
      "action": { "type": "app", "desktop": "discord.desktop",
                  "alternatives": ["com.discordapp.Discord.desktop",
                                   "discord_discord.desktop"] } }
  ]
}
  • formatVersion: must be 1. A reader that does not know the version refuses the file.
  • id: 1 to 32 characters among a-z, 0-9, _, -; it becomes the page name.
  • name (up to 24 characters), author (64), license (an SPDX identifier such as CC-BY-SA-4.0) and color (#RRGGBB) are required. description is optional (300).
  • keys and dials use the same fields as a page of GalleonCore's pages.json, and are checked by the same parser: a theme can never say what a page cannot. Unknown fields make the file invalid.
  • An icon with an extension (mute.png) is a file of icons/; one without (discord) is a name of the desktop's icon theme.

Allowed actions

A downloaded theme must not be able to run anything by itself. A theme may use: media commands, back, none, wallpaper-mode, page pointing to its own page, key (a key of the fixed list: numeric keypad, Num Lock, Backspace, F13 to F24; prefer F14 to F18 for a shortcut: on most desktops they have no default action, whereas F13 opens System Settings on KDE and F20 toggles the microphone), steam (a game by its number) and app. An application is named by its desktop file ID (firefox.desktop), never by a path. Shell commands, URLs, other pages, theme switching and the page's automatic filling (Steam games, menu entries, sorting) are refused.

One application, several installations

The same program has a different desktop file ID depending on how it was installed (deb, Flatpak, Snap). An app action may list up to 6 alternatives. When the theme is installed, the first of desktop then alternatives that exists on the machine is used; if none does, the first is kept and the user is warned.

Installing and exporting

Installing never replaces anything of the user's: the page and tab names get a number when taken, pictures are renamed after the page, the dial settings are copied only if the user asks, and nothing is written unless the whole theme is valid. Exporting shrinks pictures to what a key needs, re-encodes wallpapers as JPEG at 80 % quality or more, no larger than the screen, refuses actions a shared theme cannot hold, and checks its own output with the same validator.

Writing a theme by hand

You can build a theme without Bosun: write theme.json, add the pictures, and store them with zip -0 -X. Install it from the “+” tab of Bosun, which will list every problem it finds. Share only what you made or may redistribute; see the themes page for the content rules.

Format des fichiers de thème (version 1)

Un thème est une page de touches pour le module Stream Deck du Corsair Galleon 100 SD, avec une couleur, des réglages de molettes facultatifs et les images nécessaires. Un fichier .gctheme le transporte d’un ordinateur à l’autre. État : Bosun installe et exporte ce format ; il n’est pas encore confirmé sur le module. Le même texte est dans le dépôt : docs/THEME_FORMAT.md.

Le fichier

Un fichier .gctheme est une archive zip dont les entrées sont stockées, sans compression (par exemple zip -0 -X mon.gctheme theme.json icons/*). Les images sont déjà compressées, et refuser la compression écarte tout risque de bombe de décompression. Pour regarder dedans, renomme-le en .zip.

EntréeObligatoireContenu et limites
theme.jsonouiLe manifeste, 128 Kio au plus.
credits.txtnonTexte UTF-8 simple, 16 Kio au plus.
icons/<nom>.pngsi utiliséeUne image PNG de touche, 256 Kio et 512 × 512 pixels au plus ; 24 au maximum. Chaque image doit servir à une touche.
wallpapers/<nom>.jpgnonUne image JPEG pour l’écran, 2 Mio et 4096 × 4096 pixels au plus ; 4 au maximum.

Rien d’autre n’est accepté. Les noms de fichiers n’utilisent que des lettres, des chiffres, ., _ et -. L’archive fait 24 Mio au plus, avec 64 entrées au plus. Les images sont vérifiées d’après leur contenu, pas leur extension.

Le manifeste

{
  "formatVersion": 1,
  "id": "discord",
  "name": "Discord",
  "author": "A. Person",
  "license": "CC-BY-SA-4.0",
  "description": "Voice and chat keys for Discord",
  "color": "#5865F2",
  "keys": [
    { "key": 0, "label": "Mute", "icon": "mute.png",
      "action": { "type": "key", "key": "kp1" } },
    { "key": 1, "label": "Discord", "icon": "discord",
      "action": { "type": "app", "desktop": "discord.desktop",
                  "alternatives": ["com.discordapp.Discord.desktop",
                                   "discord_discord.desktop"] } }
  ]
}
  • formatVersion : doit valoir 1. Un lecteur qui ne connaît pas la version refuse le fichier.
  • id : 1 à 32 caractères parmi a-z, 0-9, _, - ; il devient le nom de la page.
  • name (24 caractères au plus), author (64), license (un identifiant SPDX comme CC-BY-SA-4.0) et color (#RRGGBB) sont obligatoires. description est facultative (300).
  • keys et dials reprennent les champs d’une page du pages.json de GalleonCore et sont vérifiés par le même analyseur : un thème ne peut jamais dire ce qu’une page ne peut pas dire. Un champ inconnu rend le fichier invalide.
  • Une icon avec extension (mute.png) est un fichier de icons/ ; sans extension (discord), c’est un nom du thème d’icônes du bureau.

Actions autorisées

Un thème téléchargé ne doit pouvoir rien lancer par lui-même. Un thème peut utiliser : les commandes média, back, none, wallpaper-mode, page vers sa propre page, key (une touche de la liste fixe : pavé numérique, verrouillage numérique, Retour arrière, F13 à F24 ; privilégie F14 à F18 pour un raccourci : sur la plupart des bureaux elles n’ont aucune action par défaut, alors que F13 ouvre les paramètres système sous KDE et F20 coupe le micro), steam (un jeu par son numéro) et app. Une application est désignée par son identifiant de fichier .desktop (firefox.desktop), jamais par un chemin. Les commandes shell, les URL, les autres pages, le changement de thème et le remplissage automatique d’une page (jeux Steam, entrées du menu, tri) sont refusés.

Une application, plusieurs installations

Un même programme a un identifiant .desktop différent selon son installation (deb, Flatpak, Snap). Une action app peut lister jusqu’à 6 alternatives. À l’installation du thème, le premier identifiant qui existe sur la machine, en commençant par desktop, est utilisé ; s’il n’y en a aucun, le premier est gardé et l’utilisateur est prévenu.

Installer et exporter

Installer ne remplace jamais rien de ce qui appartient à l’utilisateur : les noms de page et d’onglet reçoivent un numéro s’ils sont pris, les images sont renommées d’après la page, les réglages des molettes ne sont copiés que sur demande, et rien n’est écrit si le thème n’est pas entièrement valide. Exporter réduit les images à ce dont une touche a besoin, réencode les fonds d’écran en JPEG à 80 % de qualité au moins, pas plus grands que l’écran, refuse les actions qu’un thème partagé ne peut pas contenir et vérifie sa production avec le même validateur.

Écrire un thème à la main

Tu peux fabriquer un thème sans Bosun : écris theme.json, ajoute les images et range le tout avec zip -0 -X. Installe-le depuis l’onglet « + » de Bosun, qui liste tous les problèmes trouvés. Ne partage que ce que tu as créé ou peux redistribuer ; les règles de contenu sont sur la page des thèmes.

Format der Themendateien (Version 1)

Ein Thema ist eine Tastenseite für das Stream-Deck-Modul des Corsair Galleon 100 SD, mit einer Farbe, optionalen Drehregler-Einstellungen und den nötigen Bildern. Eine .gctheme-Datei überträgt es von einem Rechner zum anderen. Stand: Bosun installiert und exportiert dieses Format; auf dem Modul ist es noch nicht bestätigt. Derselbe Text liegt im Repository als docs/THEME_FORMAT.md.

Die Datei

Eine .gctheme-Datei ist ein Zip-Archiv, dessen Einträge gespeichert, nicht komprimiert sind (zum Beispiel zip -0 -X mein.gctheme theme.json icons/*). Bilder sind bereits komprimiert, und der Verzicht auf Kompression schließt jede Dekompressionsbombe aus. Zum Hineinsehen benenne sie in .zip um.

EintragPflichtInhalt und Grenzen
theme.jsonjaDas Manifest, höchstens 128 KiB.
credits.txtneinEinfacher UTF-8-Text, höchstens 16 KiB.
icons/<Name>.pngwenn verwendetEin PNG-Tastenbild, höchstens 256 KiB und 512 × 512 Pixel; höchstens 24. Jedes Bild muss von einer Taste verwendet werden.
wallpapers/<Name>.jpgneinEin JPEG-Bild für den Bildschirm, höchstens 2 MiB und 4096 × 4096 Pixel; höchstens 4.

Nichts anderes wird akzeptiert. Dateinamen bestehen nur aus Buchstaben, Ziffern, ., _ und -. Das Archiv ist höchstens 24 MiB groß und hat höchstens 64 Einträge. Bilder werden anhand ihres Inhalts geprüft, nicht anhand der Endung.

Das Manifest

{
  "formatVersion": 1,
  "id": "discord",
  "name": "Discord",
  "author": "A. Person",
  "license": "CC-BY-SA-4.0",
  "description": "Voice and chat keys for Discord",
  "color": "#5865F2",
  "keys": [
    { "key": 0, "label": "Mute", "icon": "mute.png",
      "action": { "type": "key", "key": "kp1" } },
    { "key": 1, "label": "Discord", "icon": "discord",
      "action": { "type": "app", "desktop": "discord.desktop",
                  "alternatives": ["com.discordapp.Discord.desktop",
                                   "discord_discord.desktop"] } }
  ]
}
  • formatVersion: muss 1 sein. Ein Leser, der die Version nicht kennt, lehnt die Datei ab.
  • id: 1 bis 32 Zeichen aus a-z, 0-9, _, -; sie wird zum Seitennamen.
  • name (höchstens 24 Zeichen), author (64), license (eine SPDX-Kennung wie CC-BY-SA-4.0) und color (#RRGGBB) sind Pflicht. description ist optional (300).
  • keys und dials verwenden dieselben Felder wie eine Seite der pages.json von GalleonCore und werden vom selben Parser geprüft: Ein Thema kann nie sagen, was eine Seite nicht sagen kann. Unbekannte Felder machen die Datei ungültig.
  • Ein icon mit Endung (mute.png) ist eine Datei in icons/; ohne Endung (discord) ist es ein Name aus dem Symboldesign des Desktops.

Erlaubte Aktionen

Ein heruntergeladenes Thema darf von sich aus nichts ausführen können. Ein Thema darf verwenden: Medienbefehle, back, none, wallpaper-mode, page auf die eigene Seite, key (eine Taste der festen Liste: Ziffernblock, Num-Taste, Rücktaste, F13 bis F24; nimm für ein Tastenkürzel F14 bis F18: Auf den meisten Desktops haben sie keine Standardaktion, während F13 unter KDE die Systemeinstellungen öffnet und F20 das Mikrofon umschaltet), steam (ein Spiel über seine Nummer) und app. Eine Anwendung wird über ihre Desktop-Datei-ID (firefox.desktop) benannt, nie über einen Pfad. Shell-Befehle, URLs, andere Seiten, Themenwechsel und das automatische Füllen einer Seite (Steam-Spiele, Menüeinträge, Sortierung) werden abgelehnt.

Eine Anwendung, mehrere Installationsarten

Dasselbe Programm hat je nach Installation (deb, Flatpak, Snap) eine andere Desktop-Datei-ID. Eine app-Aktion kann bis zu 6 alternatives auflisten. Bei der Installation des Themas wird die erste vorhandene ID verwendet, beginnend mit desktop; ist keine vorhanden, bleibt die erste erhalten und der Nutzer wird gewarnt.

Installieren und exportieren

Das Installieren ersetzt nie etwas, das dem Nutzer gehört: Seiten- und Tabnamen erhalten eine Nummer, wenn sie vergeben sind, Bilder werden nach der Seite benannt, Drehregler-Einstellungen werden nur auf Wunsch übernommen, und nichts wird geschrieben, wenn das Thema nicht vollständig gültig ist. Das Exportieren verkleinert Bilder auf das, was eine Taste braucht, kodiert Hintergrundbilder als JPEG mit mindestens 80 % Qualität und nicht größer als der Bildschirm neu, lehnt Aktionen ab, die ein geteiltes Thema nicht enthalten darf, und prüft das Ergebnis mit demselben Validator.

Ein Thema von Hand schreiben

Du kannst ein Thema ohne Bosun bauen: theme.json schreiben, Bilder hinzufügen und alles mit zip -0 -X verpacken. Installiere es über den „+“-Tab von Bosun, der alle gefundenen Probleme auflistet. Teile nur, was du selbst erstellt hast oder weitergeben darfst; die Inhaltsregeln stehen auf der Themenseite.

Formato de los archivos de tema (versión 1)

Un tema es una página de teclas para el módulo Stream Deck del Corsair Galleon 100 SD, con un color, ajustes opcionales de los diales y las imágenes que necesita. Un archivo .gctheme lo lleva de un ordenador a otro. Estado: Bosun instala y exporta este formato; aún no está confirmado en el módulo. El mismo texto está en el repositorio como docs/THEME_FORMAT.md.

El archivo

Un archivo .gctheme es un archivo zip cuyas entradas están almacenadas, sin comprimir (por ejemplo zip -0 -X mi.gctheme theme.json icons/*). Las imágenes ya están comprimidas, y rechazar la compresión elimina cualquier riesgo de bomba de descompresión. Para mirar dentro, cámbiale el nombre a .zip.

EntradaObligatoriaContenido y límites
theme.jsonsíEl manifiesto, hasta 128 KiB.
credits.txtnoTexto UTF-8 simple, hasta 16 KiB.
icons/<nombre>.pngsi se usaUna imagen PNG de tecla, hasta 256 KiB y 512 × 512 píxeles; como máximo 24. Cada imagen debe usarla una tecla.
wallpapers/<nombre>.jpgnoUna imagen JPEG para la pantalla, hasta 2 MiB y 4096 × 4096 píxeles; como máximo 4.

No se acepta nada más. Los nombres de archivo usan solo letras, dígitos, ., _ y -. El archivo tiene como máximo 24 MiB y 64 entradas. Las imágenes se comprueban por su contenido, no por su extensión.

El manifiesto

{
  "formatVersion": 1,
  "id": "discord",
  "name": "Discord",
  "author": "A. Person",
  "license": "CC-BY-SA-4.0",
  "description": "Voice and chat keys for Discord",
  "color": "#5865F2",
  "keys": [
    { "key": 0, "label": "Mute", "icon": "mute.png",
      "action": { "type": "key", "key": "kp1" } },
    { "key": 1, "label": "Discord", "icon": "discord",
      "action": { "type": "app", "desktop": "discord.desktop",
                  "alternatives": ["com.discordapp.Discord.desktop",
                                   "discord_discord.desktop"] } }
  ]
}
  • formatVersion: debe ser 1. Un lector que no conozca la versión rechaza el archivo.
  • id: de 1 a 32 caracteres entre a-z, 0-9, _, -; pasa a ser el nombre de la página.
  • name (hasta 24 caracteres), author (64), license (un identificador SPDX como CC-BY-SA-4.0) y color (#RRGGBB) son obligatorios. description es opcional (300).
  • keys y dials usan los mismos campos que una página del pages.json de GalleonCore y los comprueba el mismo analizador: un tema nunca puede decir lo que una página no puede. Un campo desconocido invalida el archivo.
  • Un icon con extensión (mute.png) es un archivo de icons/; sin extensión (discord) es un nombre del tema de iconos del escritorio.

Acciones permitidas

Un tema descargado no debe poder ejecutar nada por sí mismo. Un tema puede usar: comandos multimedia, back, none, wallpaper-mode, page hacia su propia página, key (una tecla de la lista fija: teclado numérico, Bloq Num, Retroceso, F13 a F24; para un atajo usa mejor F14 a F18: en la mayoría de los escritorios no tienen acción por defecto, mientras que F13 abre la configuración del sistema en KDE y F20 conmuta el micrófono), steam (un juego por su número) y app. Una aplicación se designa por su identificador de archivo .desktop (firefox.desktop), nunca por una ruta. Se rechazan los comandos de shell, las URL, las otras páginas, el cambio de tema y el relleno automático de una página (juegos de Steam, entradas del menú, orden).

Una aplicación, varias instalaciones

El mismo programa tiene un identificador .desktop distinto según cómo se instaló (deb, Flatpak, Snap). Una acción app puede enumerar hasta 6 alternatives. Al instalar el tema se usa el primer identificador que exista en el equipo, empezando por desktop; si no existe ninguno, se conserva el primero y se avisa al usuario.

Instalar y exportar

Instalar nunca sustituye nada de lo que pertenece al usuario: los nombres de página y de pestaña reciben un número si ya existen, las imágenes se renombran según la página, los ajustes de los diales solo se copian si el usuario lo pide, y no se escribe nada si el tema no es totalmente válido. Exportar reduce las imágenes a lo que necesita una tecla, recodifica los fondos como JPEG con una calidad del 80 % o más, no mayores que la pantalla, rechaza las acciones que un tema compartido no puede contener y comprueba su resultado con el mismo validador.

Escribir un tema a mano

Puedes construir un tema sin Bosun: escribe theme.json, añade las imágenes y guárdalo todo con zip -0 -X. Instálalo desde la pestaña «+» de Bosun, que enumera todos los problemas que encuentre. Comparte solo lo que hayas creado o puedas redistribuir; las reglas de contenido están en la página de temas.
