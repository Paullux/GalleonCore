# Gaming fallback: provenance

The bundled fallback for the GalleonCore Gaming screen is a fictional, AI-assisted illustration. It is used when no valid game cover or personal Gaming image is available, including without network access.

| File | Tool | Date | Source and generation instruction |
|---|---|---|---|
| `galleoncore_gaming_fallback.png` | ChatGPT Images (image editing), then PNG resized for the GalleonCore screen | 2026-10-27 | An image supplied by Paul Woisard was selected with the instruction `celle-ci`. The follow-up request was `mais le titre dessus en haut serait bien serait`, requesting the GalleonCore title across the top while retaining the provided gaming illustration. The exact internal generation prompt is not available; these are the original user instructions. |

Final asset: 720 × 384 PNG. Packaged as a Qt resource in the daemon; no external download is required.

This record documents the creative provenance and supplied instructions; it does not claim to reproduce any unavailable internal generation prompt.
